## 4. 출시 전 필수 체크리스트 (Play Console)
1. **웹앱 → Android 앱 패키징 (AAB)**:
   - 본 게임은 HTML5/JS 웹 게임이므로 Play Console 등록을 위해 **TWA(Trusted Web Activity / Bubblewrap)** 또는 **Capacitor**로 `.aab` (Android App Bundle, targetSdkVersion 34+) 빌드 필요
2. **개인정보처리방침 URL 등록**:
   - 학교명·반정보·아이디·닉네임 입력 및 광고 SDK 사용에 대한 개인정보처리방침 웹페이지 URL 필수 등록 (향후 서버 연결 예정 HTTPS 주소: `https://boltangi.amazonlightsail.com` — 현재 `Unattached` 상태로 미배포)
3. **비공개 테스트 (Closed Testing)**:
   - 신규 개인 개발자 계정인 경우 Play Console 정책상 **비공개 테스트(테스터 12명 이상, 14일 연속)** 완료 후 프로덕션(정식 출시) 심사 신청 가능
