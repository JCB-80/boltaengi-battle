# 볼탱이 대전 개인정보처리방침 등록 안내

앱에 포함된 정책을 공개 웹페이지에도 게시해 같은 내용을 유지합니다. 삭제 절차와 이메일 문의처는 앱을 설치하지 않은 이용자도 열 수 있어야 합니다. [개인정보처리방침](../privacy.html) · [계정 삭제 안내](../privacy.html#account-deletion)

- **개인정보처리방침 URL**에는 게시한 페이지의 HTTPS 주소를 입력합니다.
- **계정 삭제 요청 URL**에는 같은 주소에 `#account-deletion`을 붙여 입력합니다. 해당 위치에는 앱에서 삭제하는 방법과 운영자에게 이메일로 삭제를 요청하는 방법이 있습니다.
- **데이터 보안 답변**에는 로그인 서비스의 계정 식별값, 게임 계정과 닉네임, 대전 기록을 실제 배포 서버의 설정과 대조해 기재합니다.
